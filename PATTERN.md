# Pattern

This repo demonstrates the bounded teaching and progression pattern:

1. keep a curriculum
2. pick the next useful concept on purpose
3. produce one teaching or recall artifact
4. update progression state

The public claim is simple:

**pick the next teachable thing on purpose, then reinforce it in a bounded loop**

Why it exists:

- to teach progression-aware agents
- to show curriculum state as architecture
- to prove that learning loops can stay small and legible
